# ONG Amor pelo Próximo

Projeto acadêmico desenvolvido para a disciplina de desenvolvimento front-end, com o objetivo de criar uma interface web para a ONG Amor pelo Próximo.

## Sobre o projeto

O projeto apresenta páginas para divulgação da ONG, apresentação de projetos e cadastro de colaboradores.

Durante o desenvolvimento, a interface foi aprimorada com JavaScript para tornar algumas funcionalidades dinâmicas e interativas.

## Funcionalidades

- Navegação entre as páginas do projeto.
- Menu responsivo com botão de navegação.
- Exibição dinâmica dos projetos utilizando JavaScript.
- Organização dos projetos por categorias.
- Máscara para CPF, telefone e CEP.
- Validação visual dos campos do formulário.
- Feedback visual após o envio do formulário.
- Armazenamento do nome e e-mail do colaborador no `localStorage`.
- Recuperação dos dados armazenados ao acessar novamente o formulário.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

O projeto utiliza JavaScript sem frameworks ou bibliotecas externas.
