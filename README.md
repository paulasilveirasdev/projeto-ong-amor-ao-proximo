# ONG Amor ao Próximo

Projeto desenvolvido para uma ONG fictícia chamada **Amor ao Próximo**, com o objetivo de apresentar seus projetos e permitir o cadastro de pessoas interessadas em colaborar.

## Sobre o projeto

O site foi desenvolvido utilizando:

* HTML5
* CSS3
* JavaScript

## Estrutura do projeto

* `HTML/` — páginas do site
* `CSS/` — arquivos de estilização
* `JS/` — arquivos JavaScript
* `imagens/` — imagens utilizadas no projeto

## Funcionalidades

* Página inicial da ONG
* Apresentação dos projetos
* Formulário para cadastro de colaboradores
* Máscaras para CPF, telefone e CEP
* Menu de navegação responsivo
* Adaptação do site para diferentes tamanhos de tela

## Objetivo

O projeto foi desenvolvido como atividade acadêmica para colocar em prática conhecimentos de desenvolvimento web, responsividade, estilização e JavaScript.
